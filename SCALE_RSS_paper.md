# SCALE: Success-Conditioned Adaptive Latent Ensembles for Training-Free Robot Adaptation under Hidden Dynamics

## Abstract

A robot can fail when friction, payload, or contact dynamics change even though the task appearance and goal remain unchanged. Existing few-shot world-model adaptation methods either fit latent prediction residuals or update the predictor online. We propose **SCALE**, a training-free adaptation mechanism that treats the environment latent as a posterior over task-relevant dynamics hypotheses. A frozen LeWM/T2-z world model is queried with a small deterministic ensemble of latent particles. Each particle predicts a binary task event—progress toward the goal or task success—for every candidate action chunk. After execution, the real event updates the particle posterior through the closed-form solution of a KL-constrained mirror-descent problem. Action selection uses posterior expected success with a risk penalty. No world-model parameter, residual adapter, or physical-parameter estimator is trained at deployment. The primary evaluation is task success rate under hidden friction and payload shifts; latent prediction error is diagnostic only. The paper's central test is whether task-event filtering adapts a frozen world model with fewer interactions than mean-context T2-z adaptation while preserving control safety.

## 1. Core hypothesis

The latent \(z\) need not be identified as a physical parameter. It only needs to distinguish action consequences relevant to the current task. Therefore, instead of minimizing embedding error, maintain a posterior over latent hypotheses using the task event generated by the executed action:

\[
\text{latent hypothesis} \rightarrow \text{predicted task event}
\rightarrow \text{real event}
\rightarrow \text{posterior update}.
\]

This changes the adaptation target from global prediction fidelity to **task-relevant feasibility**.

## 2. Method: SCALE

Let a frozen world model produce a rollout

\[
\hat e_{1:H}=F_\theta(e_t,a_{t:t+H-1},z).
\]

Let \(\mathcal E(\hat e_{1:H},g)\in[0,1]\) be a fixed task-event head. It can be a frozen object-goal detector, a success classifier, or a deterministic geometric predicate in simulation. It is not trained at test time.

### 2.1 Deterministic latent ensemble

Start with the existing T2-z context \(z_0\). Let \(P_r\) be a fixed low-rank basis computed once from training contexts, or use the first \(r\) coordinates when no basis is available. Create a center particle and antipodal probes:

\[
 z_i=\Pi_{[0,1]^d}(z_0+\rho P_r u_i),
\]

where \(u_i\) is a deterministic spherical code. The default real-robot setting is 17 particles, rank \(r=8\), and one center particle. No learned proposal network is introduced.

### 2.2 Task-event likelihood

For candidate action chunk \(a\), each particle predicts

\[
 p_i(a)=\mathcal E(F_\theta(e_t,a,z_i),g).
\]

After executing \(a_t\), the robot emits a binary event \(y_t\): the object made progress toward the goal, or the task success predicate was reached. Use clipped Bernoulli likelihood:

\[
 \ell_i(y_t|a_t)=-y_t\log p_i(a_t)-(1-y_t)\log(1-p_i(a_t)).
\]

The event is deliberately task-level. It does not require ground-truth friction, mass, or a target latent.

### 2.3 KL-constrained posterior update

The new particle weights solve

\[
 w^{t+1}=\arg\min_{w\in\Delta^N}
 \sum_i w_i\ell_i(y_t|a_t)+
 \frac{1}{\beta}D_{KL}(w\|w^t).
\]

The closed-form update is

\[
 w_i^{t+1}=\frac{w_i^t\exp[-\beta\ell_i(y_t|a_t)]}
 {\sum_jw_j^t\exp[-\beta\ell_j(y_t|a_t)]}.
\]

This is both a Bayesian event filter and an exponentiated-gradient mirror step. It changes only a probability vector; there is no backpropagation and no parameter update.

### 2.4 Risk-aware action selection

For each action candidate, compute posterior mean and variance:

\[
 \mu(a)=\sum_iw_i p_i(a),\qquad
 \sigma^2(a)=\sum_iw_i[p_i(a)-\mu(a)]^2.
\]

Select

\[
 a_t=\arg\max_a\left[\mu(a)-\lambda\sigma^2(a)\right].
\]

The variance term prevents a high predicted success rate that depends on one fragile latent hypothesis. After a failure the probe radius expands; after a success it contracts. This is the only stateful adaptation mechanism.

## 3. Why this is not module stacking

SCALE has one new object: a task-conditioned posterior over the existing environment latent. It does not add memory retrieval, VLM attributes, residual adapters, flow steering, critic guidance, RL, or online predictor training. Those mechanisms can be studied later only if SCALE itself fails.

The distinction from recent work is testable:

- Few-Shot Residual Adaptation learns self-supervised residual corrections inside the predictor and at its output; SCALE leaves the predictor untouched and filters latent hypotheses using binary task events.
- JEPA-TTT updates the latent dynamics predictor with dense replay; SCALE performs zero training and keeps only a particle posterior.
- Feedback World Model maintains a learned feedback state and action-aware guidance; SCALE maintains an explicit posterior over task-context particles and uses a KL-constrained task-event likelihood.

## 4. Experimental requirements

### 4.1 Hardware task

Use one fixed robot and camera for all methods. Start with planar pushing because friction and payload can be changed independently while preserving object appearance. The recommended setup is ARX X5 or UR7e, a fixed RGB camera, one object, and a randomized planar target.

### 4.2 Dynamics shifts

Use three surface-friction conditions and three payload conditions. Define train, ID, unseen-combination, and extrapolation splits before collecting query episodes. The robot receives RGB, proprioception, and actions only. True physical labels are used only to construct splits and to stratify the report.

### 4.3 Episodes and interaction budget

For each physical condition collect 15 independent episodes:

- 5 episodes in the support pool;
- 5 independent query episodes;
- 5 repeatability episodes collected with a new random order or on a second day.

Evaluate \(K\in\{0,1,2,5\}\) support episodes. A query episode is never opened until the posterior update from the support prefix is complete.

### 4.4 Baselines

1. Frozen base controller.
2. Mean-context T2-z adaptation.
3. Random-context adaptation.
4. SCALE without risk variance.
5. Full SCALE.
6. Oracle context only as a diagnostic upper bound.

Do not include residual adapters, JEPA-TTT, VLMs, DTM retrieval, FRS, QGF, or RL in the main experiment. Adding them would change the scientific question and obscure the contribution.

### 4.5 Primary metric

The only primary improvement claim is paired task success rate. Report per-condition success, aggregate success, and paired bootstrap confidence intervals over episodes. Secondary measurements—terminal distance, path length, contact failures, inference latency, and embedding MSE—are diagnostics and cannot replace success rate.

### 4.6 Publishable result threshold

A submission claim is permitted only if:

1. Full SCALE improves success over mean-context adaptation at \(K=1\) or \(K=2\).
2. The paired 95% confidence interval lower bound is positive on at least one unseen friction-payload combination.
3. The gain is reproduced with a second episode order or collection day.
4. Catastrophic contact failures do not increase.
5. The method uses no parameter update and no query outcome during adaptation.

If these conditions do not hold, the correct result is a negative paper about the limits of task-event filtering, not a claim of robust physical adaptation.

## 5. Initial CPU verification

The repository includes a NumPy toy hidden-friction task and unit tests. In the current executor there is no CUDA device and no PyTorch installation, so this is an implementation smoke test rather than evidence for the robot claim. The recorded 2,000-episode smoke result is:

| method | success rate |
|---|---:|
| mean context | 73.95% |
| SCALE | 74.60% |

The small gap is intentionally not presented as a scientific result. The decisive experiment is the frozen T2-z/LeWM integration under real task success evaluation.
